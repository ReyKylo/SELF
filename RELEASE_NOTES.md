# Release Notes — Rey Professional Career OS V2

**Build date:** 2026-10-09

### Added in candidate HTML
- Functional local Career OS with Today, Discover, Pursue (list+Kanban), Connect, Documents.
- Cross-linked company contextual workspace and existing record editing.
- CSV import for company, opportunity, contact, application, and follow-up templates, confirmation and preview.
- More tile gallery and five-entry global navigation.
- Professional-only Worlds directory and blue design override.
- Link-based Career Documents and editable outreach draft/copy.

### Preserved
- Original local-first workspace source and functions, data collections, and existing URLs/routes.
- Desk Whiteboard, nested content, Notes, Journal, Calendar, People, Spark, Backpack/Voice, Vault, Trails and Postcards.
- Unmodified baseline HTML separately in source_snapshots.

### Not done / not claimed
- No active Sites project modified, and no production URL newly deployed.
- Not an automatic live job scraper, auto-apply tool, background notification service or LinkedIn auto-messenger.
- CSV import is based on exact known headers; arbitrary spreadsheet mapping and robust cross-source dedupe remain enhancements.
- Actual attachment upload to Career Documents is not implemented; use existing Backpack and links.
- Global design overhaul remains partial; existing detailed pages may retain original creative styling (no data/engine removed).
- IndexedDB, cross-device sync, production persistence and mobile microphone were not tested in this execution environment.
