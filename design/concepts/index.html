Three ways SELF could work

SELF already does a lot: tasks across Spaces, whiteboards, links, and a full career operation from pipeline to case labs. The design hasn't kept up. These are three different answers to that, each one clickable.

What I found in the repository, which every concept below responds to:

28destinations across three stacked navigation layers: sidebar (8), Career rail (10), Career Prep tabs (10, now including Work Sample).
0interviews or follow-ups on Home. renderHome() ranks tasks only, though interview and touchpoint data is already loaded in the browser.
1thing you can do with an Inbox capture: delete it. There is no way to turn it into a task or file it to a Space.

The concepts

Each prototype is a standalone HTML file with sample data. Nothing saves. Use the buttons to switch between desktop and phone width, or open one full size. Every prototype has its own light and dark theme.

01 · Ledger

Time is the spine

Every SELF record already has a date: task due dates, interview times, last-contact dates, capture times. Ledger turns each day into one ruled page, like an accounting day-book. Overdue items are "carried forward", the tally box reconciles opened against closed, and you write in one line: Kirim CV besok #Career !high.

Try

  • Type in the capture line and watch it parse into chips
  • Press Enter to file it
  • Click a bullet to close it; the balance updates
  • "Move to today" on overdue items

Wins

  • Career shows up in the day at last
  • Calmest concept, and the best at 150% text
  • Needs no schema change

Costs

  • Weak for browsing companies, boards or labs
  • Paper texture and serif type move far from Wireframe V2
  • A timeline gets long on busy weeks
02 · Desk

An analyst's deal desk

You're training for PE, VC and consulting, so the workspace looks like the job: five numbered panes on one screen (work queue, pipeline funnel with conversion, contact aging buckets, sprint, inbox), a command line, function keys and an activity tape. Built for the keyboard first.

Try

  • Click inside, then press / and type new "Kirim CV" @career !high due:mon
  • Press 1 to 5 to focus panes, j/k to move, Enter to inspect
  • find aruna filters the queue
  • ? lists every key

Wins

  • Everything visible at once, with no navigation
  • Contact aging is a real CRM signal, borrowed from receivables aging
  • Fastest for a power user

Costs

  • Breaks the contract: 36px rows, and dense panes fight 150% text
  • On a phone it collapses into a long scroll
  • Feels like work even on a rest day
03 · Rooms

Organized by what you're doing

Five rooms replace 28 destinations: Today, Work, Hunt, Study and Studio. Each room has its own layout and takes its tint from SELF's existing accent colors, and none has more than one row of sub-navigation. Any task opens in a full-screen Focus mode, and Ctrl K jumps anywhere.

rooms.htmlOpen full size ↗

Try

  • Walk through the five doors
  • Press Focus on a task; Esc leaves
  • Triage the inbox one card at a time
  • Ctrl K, type "hunt", press Enter

Wins

  • Navigation goes from three layers to two at most
  • Each existing module moves into a room; none is rewritten
  • Five doors fit the phone bar exactly

Costs

  • A new mental model, so names must be clear
  • Changes to the shell touch locked shared files
  • Room tints need discipline to stay subtle

Recommendation: Rooms, with two parts borrowed

Rooms fixes the problem that grows with every feature you add, which is depth. It does that without rewriting modules: career.js already lets the shell set its page, and boards.js and career-learning.js mount the same way, so each module moves into a room more or less intact. Ledger has the better Home and Desk the better keyboard, so I'd take one piece from each:

The build

  1. Rooms shell: a door rail, a tint per room, one sub-navigation row at most, and Focus mode.
  2. From Ledger: the capture grammar (#space !priority besok) and the agenda that merges tasks, interviews and follow-ups, both in the Today room.
  3. From Desk: the Ctrl K palette, Alt+1–5 room keys, and the stage-to-stage funnel conversion in Hunt.
  4. Left out: Ledger's paper texture and Desk's density. Both look striking, and both cost readability at 150% text.

Blueprint for the build

The full plan is in docs/design/ROOMS_REDESIGN_BLUEPRINT.md: verified line references, a route map, file paths and acceptance criteria for each phase. In short:

R0
Contract and approval

Docs only. You approve; DESIGN_CONTRACT.md gets a Rooms section. No code merges without this.

R1
Door rail and routing

New rooms.js and rooms.css; chrome() in app.js calls them. state.view is unchanged and roomOf() is derived from it. Badges count only data that is loaded.

R2
Today room

New today.js: Three for today (from priorityRank()), a merged agenda, and inbox triage built from the existing insert, patch and delete calls.

R3
Hunt and Study

SELFCareer.render({hosted}) turns the Career rail into pills. The 10 Career Prep tabs are grouped as Build, Learn and Get challenged, with the same ids.

R4
Palette and capture grammar

A pure parseCapture() function with at least 25 fixtures, including Indonesian weekdays. It never creates a Space without asking.

R5
Focus mode

A full-screen task that reuses the existing data-task-field save path. The timer stays on the device.

R6
Visual system

--room tokens and a display face for room titles only; both themes checked against WCAG AA.

Build spec for Sonnet or Haiku

You chose Rooms. docs/design/ROOMS_BUILD_SPEC.md is the complete plan for building it with Sonnet or Haiku, with nothing left to guess:

  • Motion and feel: exact durations and easings, a springy press, ripple, staggered room entrances, a room colour that glides between rooms, the aurora wash, a save tick that draws itself, toasts with Undo, a restrained celebration burst, and a circular reveal when the theme changes.
  • Drag and drop: a dependency-free engine (reference code included and syntax-checked) for mouse, touch and keyboard. The card lifts and tilts, a placeholder opens a gap, siblings glide aside, and the drop settles with a spring. Used on the My Work board, a new week calendar, the Hunt pipeline and Three for today.
  • An honest landing spot: tasks and applications have no stored order, so a card always lands where it will actually appear after saving.
  • Every screen as ASCII layouts, with data sources, interactions and empty states.
  • Nine phases (P0 hi-fi prototype first, then R0–R6), each with a recommended model and a prompt you can paste straight into Sonnet or Haiku.

Every phase: no Supabase migration, all existing smoke tests pass, and Playwright screenshots at 1366 and 390 px, 100% and 150% text, light and dark, using the fixture pattern that never writes to production.

Beyond the visuals: the product upgrade

SELF already holds four products in one: tasks, a thinking canvas, a job-search CRM and a training studio. They barely talk to each other. A company's people, applications and interviews sit on five separate pages, the canvas can't hold a company or an application, and your Career Prep work never shows up at the interview it was for. The upgrade connects what already exists and adds a few rituals. Full plan: docs/design/SELF_PRODUCT_UPGRADE_PLAN.md.

★ Dossier · Hunt

One living page per company: applications, people with days since contact, a merged timeline, the next interview, and your boards and Work Samples for it.

★ Studio Recipes · Canvas

Analyst templates instead of a moodboard: Issue Tree, Deal Thesis, IC Memo Spine, Story Bank and a Company Map that fills itself from a dossier.

★ Walkthrough · Canvas

Present any board frame by frame with smooth camera moves and a pace timer. Rehearse a case the way you'd deliver it.

★ Game Day · Hunt × Study

The interview becomes an event: countdown, dossier, that track's real Director challenges, story bank and a drill timer, then reflection and a thank-you task.

Rituals · Today

Weekly Review (wins, carry or drop, people, stale applications, next week's three), Shutdown at the end of the day, and a 5-minute Daily Drill.

Small, sharp tools

Message Composer with merge fields, Add to calendar (.ics), Radar Swipe, Harvest (cards to tasks), Structure Check, Skill Map across 36 competencies, and Proof Pack.
